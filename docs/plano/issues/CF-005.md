## Contexto

Para vender, o operador precisa ver os produtos ativos com preço e imagem. Sem catálogo, o carrinho não tem o que adicionar.

## História

**Como** operador de PDV
**quero** consultar o catálogo de produtos ativos por categoria e busca
**para** montar a venda com o preço correto.

## Regras de negócio

- **RN01** — Apenas produtos `ativo=true` aparecem no PDV.
- **RN02** — Preço exibido em BRL a partir de `preco_centavos`.
- **RN03** — Produto sem imagem usa placeholder padrão.
- **RN04** — Busca por nome (parcial) e filtro por categoria.
- **RN05** — Lista ordenada por categoria e nome.

## Critérios de aceite

- [ ] **CA01** — Lista produtos ativos com nome, preço e imagem/placeholder.
- [ ] **CA02** — Filtro por categoria funciona.
- [ ] **CA03** — Busca por nome parcial retorna resultados.
- [ ] **CA04** — Produto inativo não aparece.
- [ ] **CA05** — Estado vazio exibe "Nenhum produto disponível".
- [ ] **CA06** — Erro de rede exibe mensagem com botão "Tentar novamente".
- [ ] **CA07** — Semântica de imagem e preço para leitor de tela.

## Cenários BDD

```gherkin
# language: pt
Funcionalidade: Catálogo no PDV

  Cenário: Listar produtos ativos
    Dado que existem produtos ativos e um inativo

  Cenário: Busca sem resultado
    Quando busco por "pizza"

    Então devo ver "Nenhum produto disponível"
```

## Notas técnicas

- Camadas: `features/produtos/{presentation,domain,data}` (leitura).
- `StreamProvider`/`FutureProvider` com cache Riverpod; imagens via `Image.network` com `cacheWidth`.
- Riscos: imagens grandes — usar transformação do Storage e placeholder.
