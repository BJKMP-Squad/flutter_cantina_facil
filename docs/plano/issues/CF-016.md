## Contexto

O responsável só descobre o gasto quando abre o app. Notificações de compra e saldo baixo aumentam a sensação de controle e reduzem recargas de emergência.

## História

**Como** responsável
**quero** receber notificações de compra e de saldo baixo
**para** agir antes de o filho ficar sem crédito.

## Regras de negócio

- **RN01** — Push via FCM; token associado ao perfil do responsável.
- **RN02** — Notificar a cada venda e quando o saldo cruzar o limite definido.
- **RN03** — Responsável escolhe quais notificações receber.
- **RN04** — Notificação não expõe valor em tela de bloqueio por padrão.
- **RN05** — Deep link abre o extrato do aluno.

## Critérios de aceite

- [ ] **CA01** — Venda gera push para os responsáveis aprovados.
- [ ] **CA02** — Saldo abaixo do limite gera push uma vez por dia.
- [ ] **CA03** — Preferências desativadas param as notificações.
- [ ] **CA04** — Toque na notificação abre o extrato correto.
- [ ] **CA05** — Permissão negada não quebra o app.
